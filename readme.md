# Contribution notes

> <u>**Any usage of generative AI in your issues or pull requests will be met with a permanent ban from contributing to this repository.**</u>

Oblivion is a passion project created without any usage of generative AI whatsoever; as artists opposed to the usage of generative AI due to associated ethical and logistical issues, we intend to keep it this way.

Let this be your only warning; if you:

you are breaching our boundaries and you will be permanently banned from contributing to this repository.

## Issues
Before submitting an issue, please check the following:
* [There is not already an issue describing your issue.](//github.com/hexacryonic/Oblivion/issues?q=is%3Aissue)
  * If there is such an issue but it is closed, you are free to reopen it.
* If you have other mods, your issue occurs due to a specific set of activated mods, which includes Oblivion.
  * We are not likely to look into your issue if you have "a lot" of mods.
* Optionally: The issue is still occurring on latest commit.

Then [submit an issue](//github.com/hexacryonic/Oblivion/issues/new) and add the following information:
* Relevant crash logs (One will suffice)
* Replication steps
* A list of mods that, with high certainty, are causing the issue

You do not need to write a large description of the issue; the listed information is the minimum required for an issue that is more likely to be regarded.

## Pull requests
When submitting a pull request, please follow these guidelines:
* Keep your pull request focused. Modifications that are unrelated to the topic of your pull request will scrutinize your pull request.
* Actually test your modifications and fix any bugs that it might cause.
* Do not autoformat existing or added code.

If your pull request is accepted, we may modify it further to maintain a consistent style of code across the entire project. When contributing, we encourage you to follow the formatting established in this project; while this is largely optional, it does make us a little happier with your contribution!
